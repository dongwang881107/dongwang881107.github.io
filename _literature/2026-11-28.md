想象把乳腺体模放进一圈换能器中，每次只让一处发声，在其他位置记录散射波。减少换能器，或者让它们只能从一侧接近体模，声速图就更容易出现条纹或漏掉结构。Cao 等提出 Diff-ANO，先从数据生成一幅候选声速图，再用它预测各接收点的复波场，根据预测与观测的差距逐步校正。对作者稿的稀疏 II 设置，完整方法在表 2 中得到 30.24 dB PSNR，单独的 Inversion-Net 为 27.56 dB。这里的输入是模拟频域散射数据，真值是已知声速体模。 [原文图 6](https://arxiv.org/pdf/2507.16344v2#page=12) · [表 2](https://arxiv.org/pdf/2507.16344v2#page=16)

## 研究问题
{: #problem }

超声断层成像要从边界上有限的声波观测反推出内部的声速分布。两种欠采样的影响不同。整圈测点变稀，仍能从各个方向观察，但角度采样的间隔变大。测点集中到一段弧上，整片方向的入射和接收信息同时消失。对比度较高时，波在内部发生更强的散射。初始声速偏差若使预测波形的相位相差一个周期左右，最小化数据残差的迭代可能收敛至错误的结构。即使初值合适，每次更新仍需计算多组波场。 [原文第 1–3、11–14 页](https://arxiv.org/pdf/2507.16344v2#page=1)

## 核心创新
{: #innovation }

1. **先从观测得到初值，再用生成先验修正它。** Inversion-Net 把观测映射到声速图的空间，作为条件一致性模型的输入。模型把带噪状态映射到干净声速图，允许以少量采样步调用先验。第 7.1 节的比较显示，初值选择会影响后续结果。 [原文第 8–10 页及表 6](https://arxiv.org/pdf/2507.16344v2#page=9)
2. **由正向源场构造伴随场。** 在文中的互易结构下，接收位置可充当虚拟发射位置。算出这些位置对应的单位源场后，伴随场可由残差加权组合得到。多重网格神经算子 MgNO 近似源场，把迭代中的波场计算转化为批量网络推断。 [原文式（12）–（15）、图 3](https://arxiv.org/pdf/2507.16344v2#page=7)
3. **训练波场代理时按需生成监督数据。** 批量收敛 Born 级数（BCBS）在训练过程中由声速样本计算波场。对同一个声速场，不同源共用传播算子，因而能够批量处理。论文的参数设置中，每批取 32 个声速样本，随机选 8 个源位置。 [原文算法 1 和第 5.2 节](https://arxiv.org/pdf/2507.16344v2#page=12)

## 方法
{: #method }

模型输入为各发射位置对应的接收复波场，输出为二维声速图。推断时，Inversion-Net 提供条件图；条件一致性网络给出声速候选；在物理计算网格上，MgNO 预测波场，观测残差给出一个伴随更新。校正后的声速图映回图像网格并重新进入一致性采样。这两个步骤交替执行。作者稿的完整方案使用五次伴随校正，采样时间参数为 0.10、0.12、0.14、0.16、0.18。这里的时间指生成采样的内部参数。 [原文图 2、算法 2 和第 6.1 节](https://arxiv.org/pdf/2507.16344v2#page=10)

### 正演场为什么能帮助计算伴随？

用 <span class="literature-math">c</span> 表示声速、<span class="literature-math">Y<sub>n</sub></span> 表示第 <em>n</em> 个源的波场。对固定角频率 <span class="literature-math">ω</span>，作者用 Helmholtz 方程预测接收信号。在一次更新中，令 <span class="literature-math">e<sub>mn</sub> = Y<sub>n</sub>(r<sub>m</sub>) − y<sub>mn</sub><sup>δ</sup></span> 为第 <em>m</em> 个接收器的残差。把作者稿式（14）的组合思想写成**实对称情形**，若 <span class="literature-math">L<sub>c</sub>Y<sub>m</sub> = −δ<sub>r<sub>m</sub></sub></span>，线性叠加给出

把 <span class="literature-math">L<sub>c</sub></span> 作用在这个场的表达式上，每项的两个负号相消，得到以接收残差为权重的一组点源。因此一组接收位置的源场可为多个发射源的伴随计算复用。复波场实现需要按离散算子的伴随关系处理共轭，期刊摘要明确说明了这一点。采用代理后，接收点残差和参与梯度计算的源场都可能有误差，视觉上接近的波场也需要检查梯度方向是否准确。 [原文式（1）、（12）–（15）](https://arxiv.org/pdf/2507.16344v2#page=7) · [期刊摘要](https://doi.org/10.1088/1361-6420/aec045)

## 实验与结果
{: #experiments }

### 覆盖全环和只看一段弧，哪种设置更难？

作者选用 OpenBreastUS 的纤维腺体型（FIB，训练/测试 2700/300）和极致密型体模（EXD，1800/200）。背景声速为 1500 m/s，关注区域为 1408–1595 m/s。主实验在 500 kHz 用 CBS 合成波场，设置无噪声、10 dB 和 5 dB 三档观测。稀疏 I/II 是整环上的 64/32 个源和接收站位，局部 I/II 对应四分之一圆弧的 64 个站位及八分之一圆弧的 32 个站位。 [原文第 5.1 节和图 6](https://arxiv.org/pdf/2507.16344v2#page=11)

先看最后一行的局部 II。Inversion-Net、条件 Tweedie 加 ANO、条件一致性模型加 ANO 分别为 **26.17、28.44、29.51 dB**，完整方法的 SSIM 为 **0.9510**。从局部 II 到稀疏 II 都是 32 个站位，但完整方法在稀疏 II 达到 30.24 dB。这个差异把注意力指向角度覆盖。在原文 5 dB 示例图中，整环稀疏采样时 CBS 的周期振荡很明显，局部视角则出现有方向性的伪影。对照的 DPS 用 1000 步，作者比较 0.2、0.1、0.05 三个梯度步长并报告所选最好结果；DDS 用 50 步并结合共轭梯度；CBS 使用 500 次内层波场迭代和 30 次外层 L-BFGS 迭代。以上设置可帮助判断效果与计算量的关系。 [原文第 6.1 节、图 7–8 和表 2](https://arxiv.org/pdf/2507.16344v2#page=13)

### 多做几次波场校正，是否每个样本都改善？

在表 1 的 5 dB 条件下，稀疏 II 的平均 PSNR 由只用条件一致性模型的 **26.18** 升至三次校正的 **27.91 dB**，局部 II 则从 **27.01** 升至 **28.06 dB**。同一节还记录了部分样本第一次校正时 PSNR 下降 **0.2–0.5 dB**。均值和个例一起说明，残差校正的次数会影响重建，首步收益因样本而异。该表给出平均值，未报告独立训练或噪声重复的次数与离散程度。 [原文第 6.2 节、表 1 和图 9](https://arxiv.org/pdf/2507.16344v2#page=14)

### 把波场交给代理模型，速度与精度分别怎样变化？

作者稿表 3 在稀疏 I 下报告 Diff-ANO 平均 **1.1 s**/幅，GPU 批量 CBS 优化为 **298.5 s**/幅。这是不同流程的推断耗时。MgNO 训练本身约需 **130 A100 GPU 小时**，故离线成本需另计。要看代理带来的精度差距，可对照表 7 的固定 Inversion-Net 初值实验。MgNO-II 的正向相对均方根误差为 **0.0264**，重建 **32.07 dB / 0.9732**，CBS 波场求解器参与校正时为 **32.85 dB / 0.9803**。前向拟合更准与该表中重建更准同时出现。 [原文表 3](https://arxiv.org/pdf/2507.16344v2#page=17) · [表 7](https://arxiv.org/pdf/2507.16344v2#page=19)

还有两组延伸。稀疏 II、5 dB 下使用 400–600 kHz 的分阶段频率数据时，Diff-ANO 比单频 500 kHz 从 **30.24** 升到 **31.84 dB**，增加了频率数据和计算阶段。换用 OpenPros 的 8000 幅解剖声速图时，作者重新用 CBS 在 500 kHz 生成有限角双探头观测并加 10 dB 噪声，得到 **30.47 dB / 0.9588**，对应 Inversion-Net 的 **28.35 dB / 0.9212**。原文该节未交代完整的跨域训练/测试划分。 [原文第 6.5–6.6 节、表 4–5](https://arxiv.org/pdf/2507.16344v2#page=18)

## 结论与局限
{: #conclusions }

公开作者稿支持的结论是，在指定几何的二维合成数据上，学习先验和波场校正结合后，能以少量网络评估取得较好的声速重建。表 7 还显示，用传统求解器参与校正仍有精度空间。OpenBreastUS 的训练与观测模拟使用相同的 CBS 建模框架，文中 OpenPros 对照也从体模重新仿真波场。实际换能器响应、模型外噪声与校准失配仍需额外数据评估。条件网络还依赖按采集配置准备的配对训练数据。 [原文第 6.6、7.2–7.3 节](https://arxiv.org/pdf/2507.16344v2#page=18)

## 未来方向
{: #future }

**作者方向。** 期刊摘要把更贴近实际采集的声学物理和实测数据验证作为延伸。公开稿也指出，若系统失去所用的互易/伴随结构，正传与伴随可能需要独立建模。 [期刊摘要](https://doi.org/10.1088/1361-6420/aec045) · [作者稿第 7.3 节](https://arxiv.org/pdf/2507.16344v2#page=19)

**面向 EIT 的可检验设想。** 在固定圆形体模上，用完整电极模型做高精度正演并缓存电极场，比较数值伴随、学习代理和二者混合校正的效果。把接触阻抗变化与电导率变化作为两组对照，用独立加密网格生成电压，并留出部分激励通道用于验证。除图像误差外，检查留出电压残差、梯度方向以及无真实电导率改变时的伪影幅值。这能回答代理加速是否以误判接触漂移为代价。
