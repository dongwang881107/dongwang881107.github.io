Imagine reconstructing a CT image from noisy projections at just 50 angles. Two reconstructions might fit those data about equally well, even if one has lost small structures inside the object. A coordinate network adds a question of its own. Can the network represent those structures in the first place?

Palumbo, Massa and Benvenuto choose **which images the network can represent** alongside **how strongly the solution is pulled toward a reference image**. The paper gives conditions for adjusting both as the noise falls. In simulated CT, the network preserves some outer boundaries clearly while fine detail can still be smoothed away. Published online November 16, 2026, in *SIAM Journal on Numerical Analysis*. Selected from the November 18 curated digest. [Publisher’s article page](https://epubs.siam.org/doi/10.1137/25M1762774) · [Authors’ open manuscript v1](https://arxiv.org/html/2505.19936v1)

## Research problem
{: #problem }

In grid-based Tikhonov reconstruction, increasing <span class="literature-math">α</span> pulls the solution closer to the reference image. With a coordinate network, the reconstruction must also belong to the class of images that the network can represent, even at small <span class="literature-math">α</span>. If that class cannot express a feature, reducing the measurement noise leaves that source of error in place. The paper asks how quickly the admissible class should expand and <span class="literature-math">α</span> should decrease as measurements become cleaner. [Authors’ open manuscript, §§2.1–2.2](https://arxiv.org/html/2505.19936v1#S2)

## Core contributions
{: #innovation }

1. **A second regularization parameter.** The paper treats the index of a compact class of admissible solutions as a parameter alongside the Tikhonov weight. Approximation error from that class appears explicitly in the analysis.
2. **A construction for coordinate networks.** With an architecture and bounded weights, the outputs form a compact class. A suitable family of such networks with nonnegative outputs can approximate a broader function space.
3. **A joint parameter choice.** The paper relates the penalty and representation error to noise. Under the appropriate source conditions and approximation control, the method can attain the classical order in the linear setting. [Authors’ open manuscript, Theorems 2.2, 2.5–2.6 and 3.1](https://arxiv.org/html/2505.19936v1#S2.SS3)

## Method
{: #method }

Let <span class="literature-math">z</span> be a candidate image, <span class="literature-math">y<sup>δ</sup></span> the noisy data, and <span class="literature-math">F</span> the forward operator that predicts measurements. The authors minimize <span class="literature-math">J<sub>α</sub></span> over the compact set <span class="literature-math">X<sub>m</sub></span>. For continuous <span class="literature-math">F</span>, compactness guarantees the existence of a minimizer. More than one image can attain the minimum. [Manuscript, Eqs. (2.5)–(2.6), p. 4](https://arxiv.org/pdf/2505.19936v1#page=4)

### How do the projections become an image?

1. **Generate a candidate image.** The network maps spatial coordinates <span class="literature-math">(u, v)</span> to intensities. A final ReLU enforces nonnegativity. Evaluating one set of network weights at every pixel coordinate gives a candidate image.
2. **Predict what the scanner would measure.** Apply the forward model <span class="literature-math">F</span> to the candidate. The first term measures disagreement with the observed projections. The second penalizes departure from the reference image <span class="literature-math">x<sup>∗</sup></span>, with weight <span class="literature-math">α</span>. The CT simulations take the reference image to be zero, so both methods penalize the image norm.
3. **Update the network using those measurements.** Fit the weights separately for each set of noisy observations and read the image from the fitted network. The theorems concern global minimizers over the admissible sets. Numerical Adam runs also depend on initialization and stopping criteria. [Manuscript, §3, pp. 13–14](https://arxiv.org/pdf/2505.19936v1#page=13) · [Eqs. (4.2)–(4.3), p. 16](https://arxiv.org/pdf/2505.19936v1#page=16)

### Why does bounding the weights give a compact set?

For a fixed architecture, collect the weights and biases into a finite-dimensional vector. Imposing a lower and upper bound on each component puts the parameter vector in a closed cube. On the compact image domain, continuous activations make the map from parameters to output functions continuous in the uniform norm. Its image is compact, and it remains compact in <span class="literature-math">L<sup>2</sup>(Ω)</span>. For a nonnegative target, clipping a negative prediction to zero can only reduce the pointwise error at that location. A network family satisfying the universal approximation conditions can therefore expand its range while retaining nonnegativity. [Manuscript, Theorem 3.1 and Eq. (3.7), p. 14](https://arxiv.org/pdf/2505.19936v1#page=14)

### How should the two parameters change as noise falls?

Take <span class="literature-math">x<sup>†</sup></span> to be an exact solution closest to the reference and let <span class="literature-math">x<sub>m</sub></span> be an admissible approximation with error <span class="literature-math">e<sub>m</sub> = ‖x<sub>m</sub> − x<sup>†</sup>‖</span>. Inserting that image into the objective gives the following bound. The constant <span class="literature-math">L</span> controls how the forward operator varies close to the exact solution. [Manuscript, Theorem 2.2 and Eqs. (2.15)–(2.21), pp. 6–7](https://arxiv.org/pdf/2505.19936v1#page=6)

The first inequality holds because <span class="literature-math">x̂</span> minimizes the objective. The second bounds the projection residual using both measurement noise and image approximation error. The unscaled objective controls the data residual. Dividing by the penalty weight controls the distance to the reference image. As the noise tends to zero, the theorem takes <span class="literature-math">m → ∞</span> and imposes the following three limits.

The proof also uses weak closedness of the constraint set and the forward operator. It takes a weakly converging subsequence, identifies its limit as an exact solution because the residual tends to zero, and obtains strong convergence from convergence of the distances to the reference. For example, <span class="literature-math">α = δ<sup>2/3</sup></span> makes the noise term <span class="literature-math">δ<sup>4/3</sup></span>. It still requires <span class="literature-math">e<sub>m</sub></span> to decay faster than <span class="literature-math">δ<sup>1/3</sup></span>. A fixed network with a positive approximation-error floor cannot meet that requirement by reducing noise and the penalty alone. [Manuscript, Theorem 2.2, pp. 6–7](https://arxiv.org/pdf/2505.19936v1#page=6)

### When does the two-thirds rate apply?

The basic convergence result identifies exact solutions as limits. In the linear case, Theorem 2.6 needs a source condition that describes the solution’s spectral regularity through the forward operator and its adjoint. At smoothness index 1, the bound includes the classical <span class="literature-math">O(δ<sup>2/3</sup>)</span> term and another term <span class="literature-math">O(δ<sup>−1/6</sup> f<sup>1/4</sup>)</span>, where <span class="literature-math">f</span> is the **squared approximation error** for a penalty-dependent auxiliary solution. Given the other conditions, <span class="literature-math">f = O(δ<sup>10/3</sup>)</span> suffices to keep the second term at the same order. The nonlinear rate theorem also requires an interior solution and local derivative control, among its other hypotheses. A trend on a discrete phantom can be compared with the rate. Its validity still rests on the theorem’s assumptions. [Manuscript, Theorem 2.4, pp. 9–11](https://arxiv.org/pdf/2505.19936v1#page=9) · [Theorem 2.6 and Eq. (2.48), p. 13](https://arxiv.org/pdf/2505.19936v1#page=13)

### Supplementary Figure SM68. How does the network compare with two baselines under attenuation?

The supplement extends the comparisons to Shepp–Logan and walnut images, standard Radon and the authors’ attenuated model, and three methods. The baselines are nonnegative Tikhonov and a Plug-and-Play (PnP) method with a DnCNN denoiser. The full settings use 25 noise realizations per condition at 20, 25 and 30 dB. The authors report <span class="literature-math">ℓ<sub>2</sub></span> error, PSNR and SSIM. [Journal supplement, §§SM10–SM12](https://epubs.siam.org/doi/suppl/10.1137/25M1762774/suppl_file/supp_mat.pdf)

The extended experiments also change the network and optimization budget. Shepp–Logan uses four hidden layers and the walnut image uses six, with 256 units per layer in both cases. For each candidate penalty weight, the authors run 200 steps from each of ten random initializations. They select the initialization with the best Tikhonov objective, then run 10,000 Adam steps. A coarse grid and a finer search use the known image to select the candidate with the lowest reconstruction error. Nonnegative Tikhonov uses projected gradient steps. PnP uses a pretrained denoiser inside the iteration. Both baselines also use the true image for tuning, so the experiment compares attainable performance with that information available. [Journal supplement, §§SM8–SM10, pp. SM19–26](https://epubs.siam.org/doi/suppl/10.1137/25M1762774/suppl_file/supp_mat.pdf#page=25)

The redraw uses the **five displayed noise realizations** for attenuated Radon and a walnut image at **20 dB** from Fig. SM68. Compare the three methods along a single row to hold the noise realization fixed. Farther left means lower <span class="literature-math">ℓ<sub>2</sub></span> error in the top panel. Farther right means higher structural similarity (SSIM) in the bottom panel. Mean <span class="literature-math">ℓ<sub>2</sub></span> errors in these five cases are 14.62 for Tikhonov, 11.91 for PnP and 10.80 for the coordinate MLP. The MLP has lower error and higher SSIM in each of those pairs. The complete supplement gives the variation across the full set of runs and conditions. [Journal supplement, Fig. SM68, printed p. The MLP has lower pixel error than PnP in all 25 pairs. The median paired PSNR gain is 0.76 dB, with a range of 0.36–1.25 dB. At a fixed image size and peak intensity range, PSNR and pixel error track the same kind of discrepancy. For SSIM, the MLP records 22 wins, two ties at the displayed precision, and one loss. The first row of Figure SM67 is the exception, with PnP at 0.57 and MLP at 0.56. Better overall pixel fidelity can coexist with lower structural similarity on an individual reconstruction. [Journal supplement, Fig. SM67, p. SM93](https://epubs.siam.org/doi/suppl/10.1137/25M1762774/suppl_file/supp_mat.pdf#page=93)

The Shepp–Logan experiment with standard Radon at 20 dB shows a different pattern. Across the 25 pairs in Figures SM12–SM16, the MLP again has higher PSNR in every run, with a median paired gain of 1.51 dB. At the displayed two-decimal precision, SSIM ties 20 times and is lower five times. The MLP’s pixel-error advantage appears in both settings. The structural-similarity ranking depends on the experimental setting. [Journal supplement, Figs. ## Conclusions and limitations
{: #conclusions }

**What the theory supports.** Under the stated convergence conditions, the solution class and penalty can be chosen together, with compact-set approximation error governing how accurately the class must represent the solution. [Authors’ open manuscript, §§2.2–3.2](https://arxiv.org/html/2505.19936v1#S2.SS3)

**What the experiments leave open.** Repeating noise on a fixed image measures noise sensitivity. Generalization to unfamiliar anatomy calls for more objects and real measurements. To see whether a gain comes from the representation, nonnegativity or the optimization, vary one factor at a time under matched constraints, tuning information and compute budgets. Assess recovery of small structures separately. [Authors’ open manuscript, §§4.2–5](https://arxiv.org/html/2505.19936v1#S5) · [Journal supplement, §§SM10–SM11](https://epubs.siam.org/doi/suppl/10.1137/25M1762774/suppl_file/supp_mat.pdf)

## Future directions
{: #future }

The authors suggest evaluating more object morphologies. For electrical impedance tomography, three checks would make that question concrete. [Authors’ open manuscript, §5](https://arxiv.org/html/2505.19936v1#S5)

1. **Separate noise and model mismatch.** Compare grid-based Tikhonov and a constrained coordinate network on the same simulated conductivity phantoms. Vary voltage noise separately from electrode-position and contact-impedance errors.
2. **Select both parameters on equal measurements.** Estimate noise from repeated measurements. Use held-out excitation patterns to select the network constraint and penalty weight, and reserve a separate set of excitation patterns to report test voltage error.
3. **Evaluate conductivity and small targets.** Record held-out voltage error, conductivity bias in the target region, and boundary recovery. If voltage prediction improves while conductivity bias persists, investigate identifiability and forward-model error.
