Barbara Palumbo, Paolo Massa, and Federico Benvenuto. *SIAM Journal on Numerical Analysis*, published online November 16, 2026. Selected from the November 18 curated digest. [Publisher’s article page](https://epubs.siam.org/doi/10.1137/25M1762774)

## Research question

Many reconstructions can fit the same noisy measurements. The authors ask how to control the solutions available to a neural image representation. Their formulation has two parameters. The Tikhonov weight `α` balances data fidelity and the penalty, while the compact-set index `m` controls which functions can be considered. [Authors’ open manuscript, §2.2](https://arxiv.org/html/2505.19936v1#S2.SS2)

## How it works

For each value of `m`, the reconstruction is constrained to a compact set. The physical forward operator still predicts the observations. A network maps spatial coordinates to image intensity, with bounded weights for a chosen architecture and a nonnegative output. The family can approximate a wider class of nonnegative functions as `m` changes. The convergence results require assumptions on the forward operator and the solution, plus a parameter choice that drives the approximation error down sufficiently fast as the noise decreases. [Authors’ open manuscript, §§2.2–3.2](https://arxiv.org/html/2505.19936v1#S3)

## Evidence and limitations

The journal supplement compares nonnegative Tikhonov, Plug-and-Play, and a coordinate MLP. For the first 20 dB noise realization in the attenuated Radon simulation in Fig. SM68, the ℓ₂ errors are 14.64, 11.80, and 10.79, respectively. These values describe one simulated case. The experiments tune parameters using known ground truth, so parameter selection for actual measurements still calls for separate testing. Another simulation in the open manuscript shows that fine structures can be smoothed away, so inspection of local features remains important. [Journal supplement, §SM10 and Fig. SM68](https://epubs.siam.org/doi/suppl/10.1137/25M1762774/suppl_file/supp_mat.pdf) · [Authors’ open manuscript, §4.2](https://arxiv.org/html/2505.19936v1#S4.SS2)

## Implications for electrical impedance tomography

A practical test would use the same EIT forward model for a grid-based Tikhonov baseline and a constrained coordinate network, while varying the network bound and penalty weight independently. Hold out some electrode measurements and compare predicted voltages, conductivity error on a known simulation phantom, and boundary recovery. This would help identify which settings actually improve conductivity estimates and which smooth away small targets.
